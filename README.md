# BODYSHOP Voice PoC

Laboratorio externo y aislado para validar comunicación de voz, PoC walkie y pruebas Zello relacionadas con BODYSHOP PRO.

## Propósito

Este repositorio recoge pruebas de laboratorio sobre:

- UNIWA F400;
- Zello / PoC walkie;
- comunicación bidireccional de voz;
- pruebas futuras de voz IA, si se autorizan por separado.

## Fuera de alcance

Este repositorio no es el runtime de BODYSHOP PRO y no autoriza:

- uso en producción;
- uso en red corporativa;
- uso de datos reales de SEAT/CUPRA;
- integración con Supabase;
- integración con AI-Control-Workshop;
- cambios en el lifecycle operativo;
- automatización con impacto real.

## Relación con AI-Control-Workshop

`egaracode/AI-Control-Workshop` sigue siendo el repositorio canónico de BODYSHOP PRO.

Este repositorio es un laboratorio paralelo para validar capacidades de voz y comunicación antes de proponer cualquier integración futura.
